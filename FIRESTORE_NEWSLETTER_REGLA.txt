SIXTEEN · NEWSLETTER · REGLA FIRESTORE

La página principal ahora guarda las suscripciones en la colección:

newsletter/{correoCodificado}

Antes de probarla en producción, integra este bloque DENTRO de:
service cloud.firestore { match /databases/{database}/documents { ... } }

IMPORTANTE: no reemplaces tus reglas actuales; agrega únicamente el bloque match.

match /newsletter/{suscripcionId} {
  // La web pública solo puede crear/actualizar una suscripción con campos controlados.
  allow create, update: if
    request.resource.data.keys().hasOnly([
      'email',
      'activo',
      'consentimientoMarketing',
      'origen',
      'actualizadoEn'
    ])
    && request.resource.data.email is string
    && request.resource.data.email.size() > 3
    && request.resource.data.email.size() <= 254
    && request.resource.data.activo == true
    && request.resource.data.consentimientoMarketing == true
    && request.resource.data.origen == 'sixteen-web';

  // No permitir lectura pública de la lista de correos.
  allow read, delete: if false;
}
